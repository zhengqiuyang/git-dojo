# Git 练功房 · 竞品分析

> 调研时间：2026-09 · 结论服务于产品差异化决策

## 一、竞品全景

### 1. Learn Git Branching（learngitbranching.js.org）—— 可视化教学的"金标准"

| 维度 | 情况 |
| --- | --- |
| 形态 | 网页，零安装，支持中文 |
| 教学方式 | 关卡制 + 自由沙盒，命令对分支树的影响实时可视化 |
| 优势 | 可视化公认最强；关卡设计精良（rebase/远程都有）；社区翻译成熟 |
| 短板 | **git 是 JS 模拟的，不是真 git**（无真实文件、无暂存区体感、解决冲突无从谈起）；无 AI 辅助；界面陈旧；判分只看图不看仓库状态 |

### 2. Oh My Git!（blinry.itch.io/oh-my-git）—— 游戏化代表

| 维度 | 情况 |
| --- | --- |
| 形态 | Godot 桌面游戏（Win/Mac/Linux），itch.io 评分 4.8/5，开源 |
| 教学方式 | 卡牌式解谜，底层跑真 git，可视化时间线 |
| 优势 | 游戏化沉浸感强，适合低龄/纯新手入门 |
| 短板 | **需要下载安装，门槛高**；卡牌交互 ≠ 终端肌肉记忆；无系统性判分课程；中文支持有限；无 AI |

### 3. Coddy · Learn Git（coddy.tech）—— 最接近的 AI 玩法

| 维度 | 情况 |
| --- | --- |
| 形态 | 网页，免费 + 增值，含 AI tutor |
| 教学方式 | 交互式课程 + 真实仓库练习，AI tutor 能"读你的代码和错误并解释" |
| 优势 | **已经把 AI 助教做进 Git 学习**，是我们最直接的对标 |
| 短板 | AI 是通用答疑型（读代码/报错），**不感知整个仓库拓扑与关卡判分体系**；英文为主；无 DAG 可视化；沙盒深度不如真终端 |

### 4. Codecademy / Scrimba / Codédex

付费或半付费的通用编程教育平台，Git 课程为辅：伪终端（非真 git）、无可视化 DAG、英文/付费墙。规模大但产品针对性弱。

### 5. 中文生态（最大的流量池，也是最大的空白区）

| 产品 | 形态 | 短板 |
| --- | --- | --- |
| 菜鸟教程 / 廖雪峰 Git 教程 | 图文 | 被动阅读，无练习无反馈，"看完就忘" |
| 尚硅谷 / B站视频课 | 视频 | 被动观看，学完不会用 |
| Gitee / 高校课程 | 文档+作业 | 缺乏交互 |

中文交互式 Git 学习事实上只有 Learn Git Branching 中文版一个选择——**"中文 + 真沙盒 + 可视化 + 自动判分 + AI 助教"五者合一的产品目前不存在**。

## 二、我们的差异化定位

```
        真实 git 沙盒（不是模拟）
        × 实时 DAG 可视化
        × 自动判分闯关
        × 中文优先
        × AI 助教（看得见仓库的 Agent）   ← 本次新增的核心差异点
```

### AI 助教的三个"人无我有"

1. **全仓状态感知（State-aware）**：每次对话，服务端自动注入学员的实时上下文——当前关卡、每个学习目标的完成状态、提交图拓扑、分支/远程镜像、工作区文件状态、最近 15 条命令。通用 AI 答疑只能看到用户贴过来的报错，我们的助教**看得见整个"案发现场"**，诊断不需要用户复制粘贴。
2. **苏格拉底式护栏（Socratic guardrails）**：系统提示词明确要求"先引导、不给答案"，学员不说"给我答案"就只给最小提示——这是教育产品的关键设计，区别于"代做作业"型 AI。
3. **快捷诊断动作**：「我卡住了 / 解释上一条 / 给个小提示」三个一键动作，把"看状态 → 诊断 → 引导"压缩到一次点击，交互成本趋近于零。

### 与最接近竞品的正面对比

| 能力 | Learn Git Branching | Oh My Git! | Coddy | **Git 练功房** |
| --- | --- | --- | --- | --- |
| 真 git（非模拟） | ❌ | ✅ | 部分 | ✅ |
| 实时 DAG 可视化 | ✅ | ✅ | ❌ | ✅ |
| 自动判分闯关 | 简单 | ❌ | ✅ | ✅（状态型目标） |
| 解决冲突实操（编辑文件） | ❌ | 部分 | ❌ | ✅ |
| 模拟远程协作 | 可视化模拟 | ❌ | ❌ | ✅（裸仓库+同事克隆） |
| AI 助教 | ❌ | ❌ | 通用型 | ✅ **仓库状态感知 + 苏格拉底式** |
| 中文优先 | 翻译 | 有限 | ❌ | ✅ |

## 三、可防守的护城河建议（按优先级）

1. **把"状态感知"做深**：AI 不仅看当前状态，还能回放"你最近 5 步的操作轨迹"，指出"你其实在第 3 步就走偏了"——这是纯通用 AI 永远做不到的。
2. **AI 复盘报告**：关卡完成后生成个性化复盘（做对了什么、哪个概念薄弱、推荐下一关），沉淀学习数据。
3. **错题本 + 间隔复习**：记录学员栽过的命令/概念，AI 按遗忘曲线生成复习关卡。
4. **关卡编辑器 + 社区共创**：老师可以用 JSON 定义关卡（我们已有 goals/setup 架构，成本低），形成 UGC 内容池。
